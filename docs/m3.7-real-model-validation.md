## Bug Fixed

**OpenRouter null-content handling**: Reasoning models (e.g., `inclusionai/ling-3.0-flash-fin:free`) return `content: null` with reasoning in a separate field. The provider now handles this gracefully — `content` defaults to `""` instead of `None`.

## Known Limitations

1. **Free tier rate limiting**: OpenRouter free models are heavily rate-limited. Production use requires paid models or careful rate management.
2. **Reasoning models**: Some free models return all tokens as reasoning with no content. The provider handles this but the agent gets empty responses.
3. **LiteLLM not validated**: Requires a running LiteLLM proxy server.
4. **Session resume**: Not implemented. Storage foundation exists.
5. **Historical performance**: Needs real model runs to populate.
