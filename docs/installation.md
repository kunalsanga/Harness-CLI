# Installation

## Requirements

- Python 3.12 or higher
- pip or uv package manager

## Install from PyPI (when published)

```bash
pip install harness-engineering
# or
uv tool install harness-engineering
```

## Install from source

```bash
git clone https://github.com/kunalsanga/Harness-CLI.git
cd Harness-CLI
pip install -e .
# or
uv sync
```

## Verify installation

```bash
harness --help
harness doctor
```
